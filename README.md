## The entry

> I asked my smart fridge for life advice. It just sighed and said, 'Have you tried turning yourself off and on again?'

## How it works

`main.py` writes that single funny line (117 characters) to `/output/entry.txt`,
deterministically — the same line on every run, with no network access.
A built-in self-check gate re-reads the file and asserts it is byte-for-byte
the entry before printing it.

Run it:

```sh
python3 main.py
```
